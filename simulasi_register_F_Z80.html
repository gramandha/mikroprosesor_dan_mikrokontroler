Simulasi Register F (Flags) – Z80

Simulasi edukatif register F pada Z80. Fokus pada flag S, Z, H, P/V, N, C.

1. Operasi ALU


2. Hasil Register

A = 00H = 0
F = 00H = 00000000b

3. Isi Register F

BitFlagNamaMakna
7SSign1 jika bit-7 hasil = 1 (hasil bertanda negatif)
6ZZero1 jika hasil = 00H
55UndocumentedBit salinan/tergantung hasil pada banyak instruksi
4HHalf CarryCarry/borrow antara bit 3 dan bit 4
33UndocumentedBit salinan/tergantung hasil pada banyak instruksi
2P/VParity / OverflowParitas untuk logika; overflow signed untuk aritmetika
1NAdd/Subtract1 untuk operasi pengurangan
0CCarryCarry atau borrow dari operasi aritmetika

4. Contoh penting

A = 7FH
ADD A,01H

7FH + 01H = 80H
S = 1       → bit-7 hasil = 1
Z = 0       → hasil bukan 00H
H = 1       → F + 1 melewati bit 3
P/V = 1     → overflow signed (+127 menjadi -128)
N = 0       → penjumlahan
C = 0       → tidak ada carry keluar bit 7

F = 94H (bit 5/3 mengikuti hasil pada implementasi ini)
Catatan: Z80 membedakan overflow signed (P/V) dari carry unsigned (C). Contoh 7FH + 01H menghasilkan overflow, tetapi tidak menghasilkan carry bit-7.
